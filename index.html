一、我们收集哪些信息

1.1 游戏本体（不收集）

除下述 TapTap 登录与实名认证外，本游戏不收集任何个人信息：

  • 不要求你填写手机号、邮箱、姓名或身份证号；
  • 不读取通讯录、短信、位置、相册、麦克风、摄像头、剪贴板；
  • 不采集广告标识符（IMEI / OAID / IDFA），不做用户画像，不投放广告；
  • 不接入统计分析、崩溃上报类 SDK。

1.2 通过 TapTap 开发者服务收集的信息

为了让未成年人保护系统能够识别账号与年龄段，本游戏接入了 TapTap 登录与合规认证（防沉迷）服务。在你授权后，我们会获得：

信息类型具体内容用途是否由本游戏存储
账号标识 openId、unionId、访问令牌 识别「你是同一个玩家」，维持登录状态 仅缓存在本机，用于下次启动免登录；不上传至我方服务器
公开资料 TapTap 昵称、头像 在登录界面显示当前账号，便于你确认登录的是哪个账号 否，仅内存中显示
实名与年龄 是否已实名、年龄段（未满 8 / 8–16 / 16–18 / 成年）、剩余可玩时长 执行国家新闻出版署的未成年人游戏时段与时长限制 否，由 TapTap 服务实时返回
关于身份证号：实名认证所需的姓名与身份证号，由你在 TapTap 官方提供的实名页面直接提交给 TapTap（易玩（上海）网络科技有限公司），本游戏既不读取、也不存储、更不传输你的身份证号，我们只收到「已实名 / 未实名」和年龄段这样的结论性结果。

1.3 为完成上述功能而产生的设备信息

在登录与实名校验过程中，TapTap SDK 会读取以下设备与网络信息，用于安全风控、判断网络异常与故障排查：设备型号、操作系统版本、设备内存、设备 CPU 信息、网络连接类型（含 WiFi 信息）、Android ID。上述信息由 TapTap 处理，本游戏不单独留存，也不写入任何本地文件。

其中 Android ID 属于设备标识符：TapTap SDK 在 SDK 初始化以及你主动发起登录授权时各读取一次，用于识别同一设备上的登录会话、防范账号被盗用。本游戏不将其用于广告推送、用户画像或任何跨应用追踪。

二、保存在你设备上的数据

为了让你下次打开还能接着玩，游戏会在本机保存以下数据（仅存储在你的设备内，不会上传）：

  • 关卡进度与星级评价；
  • 生存/无尽模式的最好成绩；
  • 设置项（音效开关、虚拟按键位置与大小、语言、是否看过新手引导）；
  • TapTap 登录状态缓存（用于下次启动免去重复授权）。

这些数据通过系统提供的本地存储（WebView localStorage / 应用私有目录）保存。你可以随时删除：

  • 游戏内「设置 → 删除账号数据」，一次性删除登录状态、全部进度与设置；
  • 游戏内「设置 → 清空进度」；
  • 游戏内「设置 → 退出登录」，清除本机登录缓存；
  • 或在系统设置中清除本应用的数据 / 卸载应用。

三、申请的系统权限

网络访问（INTERNET）用于连接 TapTap 服务完成账号登录、实名认证与未成年人时段校验。游戏玩法本身无需联网，但未登录状态下无法进入游戏。
查看网络状态（ACCESS_NETWORK_STATE）用于在登录前判断网络是否可用，网络异常时给出明确提示，而不是一直转圈。

除上述两项外，本应用不申请定位、相机、麦克风、通讯录、存储读写、短信、通话记录等任何其他权限。

游戏内的触摸震动反馈依赖系统能力，本版本未单独申请振动权限；若你的设备因此没有震动，属于预期行为，不影响玩法。

五、未成年人保护

本游戏已接入实名认证与未成年人防沉迷系统，并遵守《关于进一步严格管理切实防止未成年人沉迷网络游戏的通知》：

  • 未完成实名认证的账号无法进入游戏；
  • 未满 18 周岁的玩家，仅可在周五、周六、周日及法定节假日的 20:00–21:00 游玩，其余时间将被拦截并提示可玩时段；
  • 本游戏无内购、无充值、无虚拟货币交易，不存在未成年人付费情形，因此不涉及充值限额。

若你是未满 14 周岁的儿童，请在监护人陪同下使用本游戏。监护人如需了解或删除相关信息，可通过下方邮箱联系我们；涉及 TapTap 账号本身的实名信息，也可通过 TapTap 的隐私渠道处理。

六、数据安全与存储期限

本地存档保存在你的设备中，存储期限为「直到你删除或卸载应用」。我们不运营用于存储玩家个人信息的服务器，账号与实名信息由 TapTap 按其隐私政策保存。登录令牌通过加密通道（HTTPS）传输。

七、你的权利

  • 查看：本政策随时可在游戏内「设置 → 隐私政策」查看；
  • 删除本地数据：设置内「删除账号数据」可一次性删除登录状态、全部进度与设置；也可用「清空进度」只删存档，或在系统设置中清除应用数据；
  • 退出登录 / 撤回授权：设置内「退出登录」清除本机登录缓存；卸载应用即视为撤回；
  • 咨询与投诉：通过下方邮箱联系我们，我们会在 15 个工作日内答复。

八、本政策的更新

当游戏功能变化（例如新增服务、调整收集范围）时，我们会更新本政策并在应用内重新征得你的同意。重大变更会以弹窗形式单独提示，不会默认勾选。

Privacy Policy (English)

“Color Chain” (一路拆到底) · Applies to version 0.9.1-test and later · Effective November 12, 2026 · Updated November 13, 2026 (v3)

Operator: Chen Lianglin · Contact: 3246635175@qq.com

Short version: the game itself has no account system and collects no personal data from you. At launch it uses TapTap developer services to sign you in and to verify your real-name status for child-protection purposes. Your ID card number never passes through this game.

1. Information we collect

1.1 The game itself — none. We do not ask for your phone number, email, name or ID number; we do not access contacts, messages, location, photos, microphone, camera or clipboard; we do not collect advertising identifiers; and this build contains no analytics, crash-reporting or advertising SDKs.

1.2 Through TapTap developer services. With your authorization we receive: (a) account identifiers — openId, unionId and an access token, used to recognise you across launches; (b) public profile — TapTap nickname and avatar, displayed only so you can confirm which account is signed in; (c) real-name status and age bracket (under 8 / 8–16 / 16–18 / adult) plus remaining play time, used solely to enforce the Chinese minors' play-time rules. None of these are stored on any server operated by us.

1.3 ID card number. The name and ID number required for real-name verification are submitted by you directly to TapTap (Yiwan (Shanghai) Network Technology Co., Ltd.) through TapTap's own verification screen. This game does not read, store or transmit your ID number; we only receive the conclusion (“verified / not verified” and the age bracket).

1.4 Device information. During sign-in and verification the TapTap SDK reads the following device and network details for security checks, connectivity detection and troubleshooting: device model, OS version, device memory, CPU information, connection type (including WiFi information) and Android ID. These are processed by TapTap; this game neither retains them nor writes them to any local file.

Android ID is a device identifier. The TapTap SDK reads it once when the SDK initialises and once when you actively start sign-in, to recognise the sign-in session on this device and to guard against account theft. This game does not use it for advertising, user profiling or any cross-app tracking.

2. Data stored on your device

Level progress and star ratings, best survival/endless scores, settings (sound, on-screen pad layout, language, tutorial seen), and a cached TapTap sign-in state so you need not authorize again. All of it stays in the app's private storage and is never uploaded. You can erase it via “Settings → Delete account data” (sign-in state, all progress and settings in one go), “Settings → Clear progress” (saves only), “Settings → Sign out” (cached sign-in only), or by clearing app data / uninstalling.

3. Permissions

Network access (INTERNET) is used to reach TapTap services for sign-in, real-name verification and play-time checks; gameplay itself needs no network, but the game cannot be entered while signed out. Network state access (ACCESS_NETWORK_STATE) lets us tell you clearly when the network is unavailable instead of spinning indefinitely. We request no location, camera, microphone, contacts, storage, SMS or call-log permissions. Vibration feedback relies on system capability; this build does not declare a vibration permission, so a device may not vibrate — that does not affect gameplay.

4. Third parties

This build includes two TapTap SDKs, both provided by Yiwan (Shanghai) Network Technology Co., Ltd.: TapTap Login (collects openId, unionId, access token, nickname, avatar; used for sign-in) and TapTap Compliance (collects real-name status, age bracket, play time and necessary device/network details; used for minors' play-time limits). Their privacy policy: taptap.cn/privacy-policy. Beyond these, we share no data with anyone. The game contains no in-app purchases, no ads and no payment entry of any kind.

5. Children

The game uses real-name verification and a minors' anti-addiction system. Accounts without completed verification cannot enter the game. Players under 18 may play only between 20:00 and 21:00 on Fridays, Saturdays, Sundays and statutory holidays; at other times access is blocked with the allowed window shown. There are no purchases, so no spending limits apply. If you are under 14, please play with a guardian.

6. Security and retention

Local saves remain on your device until you delete them or uninstall. We operate no server that stores players' personal data; account and verification data are held by TapTap under their policy. Sign-in tokens are transmitted over HTTPS.

7. Your rights

You may view this policy anytime in “Settings → Privacy Policy”; delete the sign-in state, all progress and settings via “Settings → Delete account data” (or clear app data); sign out to clear the cached token; and contact us at the email above for any question or complaint, answered within 15 business days.

8. Changes

If features change (new services or different data scope), we will update this policy and ask for your consent again in the app. Material changes are shown in a separate prompt and are never pre-ticked.
